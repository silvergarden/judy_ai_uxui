# 우리 집 3D 룸 투어 디자인 기준

작업하면서 정한 규칙을 모은 문서입니다. 값은 `index.html`에 실제로 들어 있는 것입니다.

## 1. 색

| 토큰 | 값 | 쓰이는 곳 |
|---|---|---|
| `--ink` | `#2b2622` | 글자, 선택된 버튼 바탕 |
| `--paper` | `rgba(255,253,249,.92)` | 카드 바탕(뒤가 살짝 비침, 흐림 10px) |
| `--line` | `rgba(60,45,30,.14)` | 카드와 버튼 테두리 |
| `--accent` | `#c8102e` | 자동 투어 버튼, 현재 위치 표시 |
| `--oak` | `#b98a55` | 나무색 기준 |
| 초점 테두리 | `#1f5fbf` 2px | 키보드로 옮겨 갈 때 |

- 화면 바탕과 카드는 따뜻한 흰색, 글자는 따뜻한 검정입니다. 무채색 회색은 쓰지 않습니다.
- 빨강은 "지금 하는 일"(자동 투어)과 "지금 있는 곳"(위치 표시)에만 씁니다.
- 3D 재질 색은 sRGB 값을 선형 값으로 바꿔 넣습니다. 바꾸지 않으면 빨강이 분홍으로 뜹니다.

## 2. 글자

- 서체: 기기 기본 한글 서체(Apple SD Gothic Neo, Pretendard, Noto Sans KR, 맑은 고딕 순)
- 크기: 방 이름 25px(굵기 800), 제목 17px, 버튼 14.5px, 보조 글 14px. 14px보다 작은 글자는 쓰지 않습니다.
- 실제 사진 크게 보기: 제목 22px, 쪽수 17px(숫자 너비 고정)

## 3. 배치

화면 네 모서리에 카드를 하나씩 둡니다. 가운데는 3D 화면을 위해 비웁니다.

| 자리 | 내용 |
|---|---|
| 왼쪽 위 | 홈 버튼과 제목, 방 이름, 자동 투어·위에서 보기·조작 안내 버튼. 너비 396px 고정 |
| 오른쪽 위 | 평면도와 방 이름 버튼 13개. 너비 250px |
| 오른쪽 아래 | 그 방의 실제 사진. 한 줄로 나열하고 좌우 스크롤은 쓰지 않음 |
| 왼쪽 아래 | 조작 안내(필요할 때만 열림) |

- 좁은 화면(너비 720px 이하)이나 눕힌 휴대폰(높이 520px 이하): 평면도와 사진은 접고, 오른쪽 아래의 [평면도] [실제 사진] 버튼으로 엽니다.
- 눕힌 휴대폰: 평면도와 방 이름 버튼을 옆으로 나란히 놓아 스크롤 없이 보이게 합니다.
- 카드끼리 겹치거나 화면 밖으로 나가면 안 됩니다. 화면 크기 7종으로 확인합니다.

## 4. 버튼

- 모양: 알약형, 흰 바탕, 1px 테두리. 선택되면 `--ink` 바탕에 흰 글자.
- 좌우 여백을 넉넉히 둡니다(기본 16px).
- 글자가 바뀌는 버튼(자동 투어 ↔ 투어 멈춤 ↔ 이어서 투어, 위에서 보기 ↔ 걸어서 보기, 속도)은 너비를 고정하고, 아이콘과 글자의 시작 위치도 움직이지 않게 합니다.
- 아이콘과 글자를 함께 씁니다. 아이콘만 있는 버튼에는 읽어 줄 이름을 붙입니다.
- 속도는 "속도 1.0 배속", "속도 1.5 배속", "속도 2.0 배속" 세 단계입니다.
- 실제 사진 크게 보기의 버튼은 반투명 흰색으로 가볍게 둡니다. [닫기]는 글자로, 넘김은 큰 꺾쇠로.

## 5. 조작

- 걸어서 보기: `W` `A` `S` `D` 또는 방향키, 드래그로 둘러보기, 바닥을 눌러 이동
- 평면도를 누르거나 방 이름 버튼을 누르면 이동. 이때 보고 있던 방식(위에서 보기, 걸어서 보기)은 유지
- 자동 투어는 멈춘 자리에서 이어 감. 이전 방, 다음 방으로 건너뛸 수 있음
- 홈 버튼(집 아이콘과 제목)을 누르면 처음 상태로 돌아감
- 위에서 보기의 현재 위치는 뒤집은 빨간 원뿔이 위아래로 통통 뛰는 모양. 방 이름 글자와 수직선은 넣지 않음
- 문은 가까이 가면 열림

## 6. 유니버설 디자인

- 터치 기기에서 누르는 곳은 44px 이상
- 모든 기능을 키보드로 쓸 수 있고, 초점 테두리가 보임
- 방 이름이 바뀌면 화면 낭독기가 읽어 줌(`aria-live`). 여닫는 버튼에는 `aria-expanded`, 켜고 끄는 버튼에는 `aria-pressed`
- 실제 사진 크게 보기 안에서는 초점이 밖으로 나가지 않고, `Esc`로 닫힘
- 움직임 줄이기 설정을 켠 기기에서는 통통 뛰는 움직임과 부드러운 이동을 줄임
- 터치 기기에서는 조이스틱을 좌우로 바꿀 수 있음(왼손, 오른손)

## 7. 3D 모형

- 단위는 미터. 실내 층고 2.3m, 전실·세탁실·발코니는 2.75m(추정)
- 최종 모습은 입주 후 사진을 따르고, 입주 전 사진은 구조 확인에만 씀
- 실제 제품이 확인된 것은 제품 치수를 따름. 확인하지 못한 치수는 사진으로 추정
- 사진에 있어도 집주인이 빼 달라고 한 물건은 넣지 않음

## 8. 개인 정보

- 단지 이름과 동·호수는 쓰지 않음. 부제는 `**마을 ***** *차 37평`
- 사진 파일 이름은 번호만, 촬영 정보(EXIF)는 지움
- 검색 엔진이 수집하지 않도록 `noindex` 표시
