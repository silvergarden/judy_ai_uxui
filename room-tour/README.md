# 우리 집 3D 룸 투어

![우리 집 3D 룸 투어 시연](%28Fable%29%20room-tour-v1.0.gif)

Fable 5.2와 대화하며 만든 우리 집 3D 룸 투어입니다. 코드는 직접 쓰지 않았습니다.

- 바로 보기: https://silvergarden.github.io/judy_ai_uxui/room-tour/ (실제 사진 없는 공개판)
- 작업 기간: 2026. 11. 16.~2026. 11. 17.
- 작업 시간: 약 10시간
- 대상: 집에 와 보지 못한 가족과 지인, 입주 때 모습을 남겨 두려는 나

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 룸 투어 전체. 브라우저로 열면 됩니다(인터넷 연결 필요 없음). |
| `three.min.js` | 3D 라이브러리. `index.html`과 같은 위치에 두어야 합니다. |
| `DESIGN.md` | 색, 배치, 버튼, 조작, 유니버설 디자인 기준을 정리한 문서 |
| `check.py` | 자동 점검 스크립트. `python3 check.py`로 실행합니다(playwright와 크롬 필요). 사진이 있으면 72개, 없으면 65개 항목을 봅니다. GitHub Actions가 바뀔 때마다 자동으로 돌립니다. |
| `linkedin-post.md` | 작업 후기 |
| `(Fable) room-tour-v1.0.mp4`, `(Fable) room-tour-v1.0.gif` | 시연 영상(40초, 소리 없음). GIF는 위에서 보기 부분 17초 미리 보기 |

## 조작

- 걸어서 보기: `W` `A` `S` `D` 또는 방향키로 이동, 드래그로 둘러보기, `Shift`로 빠르게
- 바닥이나 평면도를 누르면 그 자리로 이동
- 방 이름 버튼으로 바로 이동(13곳)
- 위에서 보기, 자동 투어(투어 멈춤, 이어서 투어, 이전 방, 다음 방, 속도 3단계)
- 터치 기기에서는 조이스틱으로 이동

## 알아 둘 점

- 벽과 방 크기는 평면도를 따랐지만, 가구 치수와 일부 층고는 사진을 보고 추정했습니다. 치수를 재는 용도로는 맞지 않습니다.
- 단지 이름과 동·호수는 넣지 않았습니다.
- 실제 사진 27장은 개인 정보 보호를 위해 이 저장소에 올리지 않았습니다. 같은 폴더에 `photos/01.jpg`~`27.jpg`를 두고 열면 방마다 사진 패널이 나타나고, 없으면 사진 패널과 [실제 사진] 버튼이 숨겨집니다. `photos/` 폴더는 `.gitignore`에 넣어 실수로 올라가지 않게 했습니다.
- 시연 영상에는 실제 사진이 나옵니다.
