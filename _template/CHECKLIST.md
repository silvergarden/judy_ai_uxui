# 새 작업 올리기 전 체크리스트

새 작업을 올릴 때 위에서부터 차례로 확인합니다.

## 1. 폴더 만들기

- [ ] 영문 소문자와 `-`로 된 폴더를 만든다 (예: `travel-app`)
- [ ] 결과물 파일 이름을 `index.html`로 둔다
- [ ] `_template/README.md`를 복사해 폴더 안 `README.md`로 채운다
- [ ] `DESIGN.md`(디자인 시스템), 있으면 `PRD.md`를 넣는다

## 2. 개인 정보 확인

- [ ] 실제 집, 얼굴, 이름, 주소, 전화번호가 나오는 사진이나 글이 없다
- [ ] 다른 사람의 작업이면 원본이 누구 것인지 README에 적었다
- [ ] 사진을 넣었다면 촬영 정보(EXIF)를 지웠다
- [ ] 올리면 안 되는 폴더는 `.gitignore`에 넣었다

## 3. 시연 영상

- [ ] 영상은 1분 안팎, GIF는 앞부분 15~20초로 만든다
- [ ] GIF는 5MB를 넘지 않게 한다 (첫 화면이 느려지지 않도록)
- [ ] 파일 이름은 `작업이름-v1.0.mp4`, `작업이름-v1.0.gif`처럼 맞춘다

## 4. 작업 목록에 추가

- [ ] `works.json`의 `works`에 새 작업 한 덩어리를 넣는다 (형식은 파일 맨 위 `_사용법`)
- [ ] README와 사이트 첫 화면의 최신 작업 3개, 전체 작업 표는 자동으로 바뀐다. 손으로 고치지 않는다.

## 5. 올리고 확인

- [ ] 새 브랜치에서 PR로 올리고, 자동 점검이 있으면 통과를 확인한 뒤 합친다
- [ ] 1~2분 뒤 `https://silvergarden.github.io/kwonjeongeun_ai_uxui/폴더이름/`이 열리는지 확인한다
- [ ] 휴대폰에서도 한 번 열어 본다
