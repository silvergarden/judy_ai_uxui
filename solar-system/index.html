실제와 같은 것
공전 주기, 궤도의 모양, 자전축의 기울기는 실제와 같습니다.
실제와 다른 것
행성과 위성은 실제보다 훨씬 크게 보입니다.
바깥쪽 궤도 사이의 간격은 실제보다 좁습니다. [설정]의 ‘실제 비율’에서 실제 간격을 볼 수 있습니다.
달은 실제보다 지구에 훨씬 가까이 있습니다.
목성과 토성의 위성은 실제보다 느리게 돕니다.
실제 자료가 아닌 것
행성 표면의 무늬와 소행성대·카이퍼대·은하수의 점은 실제 모습이 아닙니다.
달, 세레스, 핼리 혜성의 위치는 근삿값입니다.
