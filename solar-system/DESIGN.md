# 참고 웹사이트 디자인 시스템 (추출본)

- 출처: 참고한 커피 브랜드 웹사이트의 홈 화면
- 추출 방법: 2026-11-12에 실제 페이지를 열어 CSS 변수와 계산된 스타일을 읽음. 홈 화면 한 장만 본 것이라 하위 페이지 전용 스타일은 빠져 있을 수 있음.
- 성격: Shopify 기반의 스페셜티 커피 구독 사이트. 따뜻한 크림색 종이 위에 짙은 갈색 잉크, 세리프 본문, 모노 대문자 라벨. 장식 대신 여백과 사진으로 말하는 편집 디자인.

### 1.4 색 사용 원칙 (관찰)

- 무채색이 없다. 검정, 회색, 흰색 모두 노란 기가 도는 따뜻한 색이다.
- 화면의 대부분은 종이색과 잉크색 두 가지다. 가장 많이 쓰인 글자색은 `#1A1916`, 그다음이 `#F5F2EC`.
- 민트(`#6FFFB1`)는 "지금 활성인 것"과 "누르면 이동하는 것"에만 아주 조금 쓴다. 민트 위 글자는 `#1A1916`.
- 코랄(`#FF4800`)은 부분 강조가 아니라 화면 전체를 덮는 브랜드 색으로 쓴다.
- 그림자는 거의 없다. 구분은 1px 반투명 선과 바탕색 차이로 한다.

# 태양계 3D 모형 디자인 시스템 (현재 상태)

- 기준: 2026-11-13 게시본 (게시 62번째)
- 대상: 2026년 초등학교 6학년 (2022 개정 교육과정)
- 성격: 관측 계기판. 화면 전체가 우주이고, 그 위에 선과 꺾쇠로만 된 틀을 얹는다.

## 1. 색

### 선별 기준

1. **참고 사이트의 다크 테마 토큰만 쓴다.** 라이트와 코랄 테마의 바탕색은 쓰지 않는다.
2. **값을 바꾸지 않는다. 예외는 셋.** 버튼 테두리는 바탕과 3:1 이상이 되도록 크림 38%(`--border-control`)를 쓴다. 우주의 깊이를 위해 바탕을 `#0A0908`로 내렸고, 닫기 버튼의 호버에 `#45423D`를 썼다. 둘 다 참고 사이트에 없는 값이며 같은 따뜻한 색조로 정했다.
3. **강조색은 둘, 역할은 겹치지 않는다.** 코랄은 켜진 조작 상태, 민트는 선택한 천체.
4. **이 배치는 참고 사이트와 반대다.** 참고 사이트에서 민트는 활성 상태, 코랄은 화면 전체의 브랜드 색이다. 요청에 따라 서로 바꿨다.
5. **읽을 수 없는 색은 뺀다.** `#6B665D`는 어두운 바탕에서 대비가 약해 글자로 쓰지 않는다.
6. **초록 `#4ADE80`은 뺀다.** 민트와 가까워 강조가 갈린다.
7. **천체의 색은 건드리지 않는다.** 행성 표면, 태양 빛, 대기, 천체 버튼의 색 점은 정보를 담은 색이다.

### 토큰

- 공개되는 코드의 주석에는 출처 브랜드 이름을 쓰지 않고, 각 색의 역할만 적는다. 출처는 이 문서에만 남긴다.

## 3. 형태

- **틀(`.frame`)**: 거의 투명한 면, 1px 테두리, 직각 모서리. 왼쪽 위와 오른쪽 아래에 2px 굵기, 13px 길이의 꺾쇠.
- **버튼**: 투명 바탕, 1px 테두리, 직각, 안쪽 여백 5px 11px. 켜지면 코랄로 채우고 글자는 `#1A1916`, 굵기 700.
- **천체 버튼(칩)**: 안쪽 여백 4px 7px, 사이 4px. 넓은 화면에서 첫 줄에 11개, 둘째 줄에 왜소행성 2개가 들어온다.
- **낱말 풀이**: 풀이가 있는 낱말은 점선 밑줄. 누르면 민트 제목과 한두 문장의 풀이가 작은 틀로 뜬다. 다른 곳을 누르거나 Esc로 닫는다.
- **정보 카드**: 분류·이름·닫기 버튼이 있는 머리 부분은 고정하고, 점선 아래의 내용만 스크롤된다.
- **정보 카드의 높이**: 넓은 화면에서는 아래로 쓸 수 있는 자리까지 늘린다. 카드와 좌우로 겹치는 판(설정 판, 조작 띠, 회전 구)이 있으면 그 위 16px까지, 없으면 화면 아래 여백 16px까지(줌 UI·조작 띠의 아래 끝과 같은 선). 내용이 더 짧으면 내용 높이까지만. 모바일은 화면의 38%까지 그대로.
- **낱말 풀이 상자**: 글줄이 실제로 차지하는 폭에 맞춰 줄인다(최대 288px). 안쪽 여백은 10px 12px로 늘 같다.
- **탐구 질문**: 쉐브론 + "Q." + 질문. 누르면 답이 펼쳐진다. 카드 높이는 질문이 모두 접힌 상태로 고정하고, 답을 펼치면 카드 안에서 스크롤된다.
- **재생/일시정지**: 채운 아이콘 + 글자. 두 상태가 같은 폭("일시정지" 기준).
- **[설정] 버튼**: 열리면 글자가 "닫기"로 바뀌고 닫기 버튼의 색을 쓴다.
- **쉐브론**: 접혔을 때 오른쪽(>), 펼치면 아래를 향한다. 제목 앞에 둔다.
- **눈금 띠**: 1px 중심선에 같은 길이의 눈금, 양 끝 눈금 포함. 현재 값은 3px 굵기의 코랄 표시.
- **간격 기준**: 요소 사이 10px. 틀 안쪽 여백은 조작 띠 6px 8px, 설정 판 10px 12px, 정보 카드 14px 16px 16px, 줌 UI 14px 6px 16px.

| 조작 띠 | 아래 가운데 | 재생/일시정지, 시간 흐름 띠, 설정/닫기 |
| 설정 판 | 조작 띠 위 (접힘) | 천체 13개(두 줄), 궤도 간격(좁혀서 보기/실제 비율), 오늘 날짜로, 전체 보기, 좌표 눈금, 빛 번짐 |
| 줌 UI | 오른쪽 아래 (모바일은 오른쪽 위 모서리) | +, 세로 눈금 띠, −, 배율. "줌" 글자는 없다. 모바일은 눈금 띠를 짧게 |

- 넓은 화면에서 카드가 열리면 카드가 가리는 폭의 절반만큼 장면을 왼쪽으로 옮긴다. 모바일에서는 안내 제목 아래와 카드 위 사이의 가운데로 올린다.
- 설정 판과 조작 띠는 줌 UI 자리를 비우도록 최대 폭을 제한한다. 정보 카드와 줌 UI 사이는 16px.
- 층 순서: 장면 < 조준 표시와 이름표 < 머리글 받침 < 줌 UI < 정보 카드와 설정 판.
- 머리글 받침: 왼쪽 위 640px 폭에만 깔고 오른쪽으로 옅어진다. 천체와 카드를 잇는 선을 가리지 않기 위해서다.
- 모바일: 설정 판이 열린 동안 정보 카드는 숨긴다. 카드나 설정 판이 열리면 회전 구도 숨긴다. 카드 높이는 화면의 38%까지. 세로로 긴 화면에서는 기본 관측 거리를 늘려 폭 안에 들어오게 한다.
- 시점 회전 구: 황도면, 자오선 둘, 황도 북극(점), 춘분점 방향(코랄 사각형)을 지금 보는 방향 그대로 그린다. 끌거나 화살표 키로 돌린다.

## 8. 말과 표기

- 과학 선생님이 학생에게 말하듯 쓴다. "~습니다"로 끝낸다.
- 보는 사람의 관점에서 쓴다. "어림하여 그렸다", "알아 둘 점"처럼 만든 쪽의 관점이 드러나는 말은 쓰지 않는다. "보입니다", "실제와 다릅니다"로 쓴다.
- 안내문은 학생이 알아야 할 것만 짧게 쓴다. 한 문장에 한 가지.
- 이름을 하나로 맞춘다.

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 시간 흐름 | 속도, 배속 |
| 관측 거리 (태양 기준) | 시점 거리 |
| 궤도 간격: 좁혀서 보기 / 실제 비율 | 거리 방식, 압축 |
| 좌표 눈금 | 눈금 |
| 설정 / 닫기 | 더 보기 |

- 날짜는 "2027년 4월 9일", 빛의 시간은 "빛으로 8분 10초"로 쓴다.
- 안내문 전문:
  - 실제와 같은 것: 공전 주기, 궤도의 모양, 자전축의 기울기는 실제와 같습니다.
  - 실제와 다른 것: 행성과 위성은 실제보다 훨씬 크게 보입니다. / 바깥쪽 궤도 사이의 간격은 실제보다 좁습니다. [설정]의 ‘실제 비율’에서 실제 간격을 볼 수 있습니다. / 달은 실제보다 지구에 훨씬 가까이 있습니다. / 목성과 토성의 위성은 실제보다 느리게 돕니다.
  - 실제 자료가 아닌 것: 행성 표면의 무늬와 소행성대·카이퍼대·은하수의 점은 실제 모습이 아닙니다. / 달, 세레스, 핼리 혜성의 위치는 근삿값입니다.

## 11. 게시 전 점검

`python3 check.py`를 실행한다. 창 크기 다섯 가지(1100×680, 800×860, 390×760, 실제 휴대폰 앱 안 브라우저에 맞춘 393×615)에서 아래를 확인한다. 현재 85개 항목이 통과한다.

1. 도입 연출이 30%에서 50%까지 한 방향으로만 오른다.
2. 글꼴 두 가지가 불러와진다.
3. 빛 번짐이 기본으로 꺼져 있다.
4. 재생과 일시정지 버튼의 폭이 같다.
5. 회전 구를 끌면 시점이 돈다. 되돌리기 버튼이 나타나고, 누르면 돌아온 뒤 사라진다.
6. 설정 판과 줌 UI가 겹치지 않는다.
7. 천체를 선택하면 카드와 조준 표시가 나온다.
8. 줌 UI와 정보 카드가 겹치지 않는다.
9. 넓은 화면에서 천체와 카드를 잇는 선이 보인다.
10. 모바일에서 조준 표시가 안내 제목과 카드 사이에 들어온다.
11. 선택한 천체의 중심이 카드에 가려지지 않는다.
12. 선택 직후 줌이 100%다.
13. 달을 선택하면 카드에 위상이 나오고 시간 흐름이 느려진다.
14. 카드에 탐구 질문이 있고, 낱말을 누르면 풀이가 뜬다.
15. 홈 아이콘이 처음 상태로 되돌린다.
16. 콘솔 오류가 없다.

- 점검이 잡지 못하는 것: 실제 기기의 부드러움, 터치 조작, 게시된 주소에서의 글꼴 로딩, 눈으로 봐야 아는 균형과 색. 이 넷은 게시본을 직접 열어 확인한다.
- `check.py`는 작업 환경의 경로(`/tmp/test/lib`의 라이브러리 등, 큰 화면 1920×1080)에 맞춰져 있어, 다른 컴퓨터에서 돌리려면 경로를 고쳐야 한다.

- 모형 안의 글은 humanizer 기준과 국립국어원 맞춤법 기준으로 점검했다. 탐구 질문의 답이 바로 위 설명에 먼저 나오지 않게 한다.
- 조작 안내 문구는 넣었다가 요청에 따라 뺐다. 안내는 화면 낭독기용 설명에만 있다.
- 남은 것: 화면 낭독기가 카드의 실시간 값을 반복해 읽을 수 있다(보류). 1배 화면의 버튼 높이 26px은 터치 권장 44px에 못 미친다. 화면 낭독기와 200% 확대는 직접 확인하지 못했다.

## 13. 참고 사이트에서 가져오지 않은 것

- 서체(ABC Marist, ABC Diatype): 유료이고, 계기판 성격에 맞춰 Space Mono와 Pretendard를 쓴다.
- 큰 섹션 여백, 세리프 본문, 사진 중심의 편집 구성: 한 화면짜리 도구에는 맞지 않는다.
- 가져온 것: 다크 테마 색 토큰, 직각 모서리, 1px 반투명 선으로 구분하는 방식, 작은 대문자 라벨.
