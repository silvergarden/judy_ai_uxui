# CampusFlow v3.0 디자인 시스템

- 대상: 대학생용 플래너 CampusFlow의 개선안 v3.0 (웹 프로토타입 `index.html`, Figma의 v3.0 개선안 섹션)
- 기준일: 2026. 11. 27.
- 참고한 곳: thinkingmachines.ai/inkling, trysundrop.app, allo.joshpuckett.me. 2026년 11월에 실제 페이지를 열어 색, 서체, 버튼 모양을 읽고 조합했다.
- 성격: 연회색 바탕 위 흰 카드. 글자와 버튼은 검정, 색은 의미가 있을 때만 쓴다.

---

## 1. 정체성과 주요 Task

CampusFlow는 수업, 마감, 공부 시간이 서로 어긋나지 않게 맞춰 주는 도구다. 원본 사이트의 약속은 "조금 더 여유로운 대학 생활"이다. 화면과 기능은 아래 세 가지 Task를 기준으로 판단한다.

| 순서 | Task | 목표 | 기준 |
|---|---|---|---|
| 1 | 공지·강의계획서로 일정 넣기 | 빈 첫 화면에서, 직접 입력하지 않고 붙여 넣기만으로 강의 1개와 마감 2건을 넣는다 | 없음 |
| 2 | 우선순위로 공부 계획 만들기 | 과목별 중요도만 고르면 빈 시간에 공부 시간이 들어간다 | 1분 |
| 3 | 이번 주 일정 확인하기 | 앱을 열자마자 다음 수업과 가장 급한 마감을 안다 | 5초 |
| 4 | 바뀐 일정에 다시 맞추기 | 계획이 틀어졌을 때 말 한마디와 확인 한 번으로 공부 계획을 다시 맞추고, 되돌릴 수 있다 | 없음 |

Task 1은 아무것도 없는 상태에서 시작하고, Task 2~4는 앞 Task의 결과에서 이어진다.

## 2. 색

### 2.1 바탕과 글자

| 토큰 | 값 | 쓰이는 곳 |
|---|---|---|
| `--bg` | `#F2F2EF` | 화면 바탕 |
| `--card` | `#FFFFFF` | 카드, 사이드바, 입력칸 |
| `--card-border` | `#DEDED8` | 카드 테두리 |
| `--line` | `#E5E5E2` | 구분선 |
| `--ink` | `#191919` | 글자, 채움 버튼 |
| `--muted` | `#676767` | 보조 글자, 빈 상태 문구, 도우미 말의 예시 줄 |
| `--placeholder` | `#6E6E6A` | 비활성 버튼 글자 |
| `--ph` | `#A6A6A1` | 입력칸 안내 글 |
| `--input-border` | `#8C8C88` | 입력칸과 테두리 버튼의 선 |
| `--soft` | `#EBEBE7` | 선택된 메뉴, 비활성 버튼 바탕 |
| `--selected-bg` | `#E4E4DE` | 선택된 칩 |
| `--focus` | `#0155BF` | 키보드 초점 테두리 |

입력칸 안내 글 `#A6A6A1`은 흰 바탕에서 대비가 약 2.5:1이다. 꼭 필요한 정보는 칸 위 라벨에 두고, 안내 글에는 예시만 둔다.

### 2.2 의미가 있는 색

| 토큰 | 값 | 뜻 |
|---|---|---|
| `--today-bg` | `#FFF4D6` | 시간표의 오늘 열 |
| `--live` / `--live-bg` | `#0B7A5C` / `#E7F4EF` | 순공 측정 중 |
| `--danger` / `--danger-bg` | `#C8372A` / `#FDECEA` | 지난 과제, 모자란 시간, 삭제 |
| `--warn` / `--warn-bg` | `#9A5B00` / `#FDF1DC` | 3일 안 마감 |

빨강은 위험이 있는 곳에만 쓴다.

### 2.3 강의 블록과 색 점

| 토큰 | 선 | 바탕 |
|---|---|---|
| `--e1` | `#0155BF` | `#CCDDF2` |
| `--e2` | `#9CC355` | `#D9E8BE` |
| `--e3` | `#0E9972` | `#C5E7DD` |
| `--e4` | `#FFCE52` | `#FFE7A9` |

색 점 팔레트는 다섯 가지다. `#0155BF`, `#FFCE52`, `#0E9972`, `#9CC355`, `#F7A224`. 메뉴마다 제목 오른쪽에 색 점을 겹친 그림이 하나씩 있고, 빈 상태와 로고에도 같은 점을 쓴다. 겹치는 부분은 곱하기(multiply)로 섞는다.

### 2.4 AI만 예외

사이드바의 'AI 연결됨' 아이콘에만 형광 그라데이션 선을 쓴다. `#39FF14` → `#00E5FF` → `#B84DFF` → `#E23BE8`. 그림자는 쓰지 않고, 다른 아이콘에는 쓰지 않는다.

## 3. 타이포그래피

| 역할 | 글꼴 | 굵기 |
|---|---|---|
| 화면 제목, 카드 제목, 달력의 연·월 | Hahmlet | 400, 500 |
| 본문, 버튼, 라벨 | Noto Sans KR | 400, 500, 700, 900 |

- 화면 제목 영역은 높이를 168px로 고정해 메뉴를 바꿔도 제목 위치가 움직이지 않는다.
- 숫자는 `tabular-nums`로 자릿수 폭을 맞춘다.
- 본문 16px, 줄 간격 1.5.

---

## 4. 모양

| 요소 | 값 |
|---|---|
| 카드 | 흰 바탕, 1px 테두리, 모서리 24px 안팎 |
| 버튼 | 알약 모양(모서리 999px). L 높이 48px, M 높이 40px |
| 입력칸, 선택 상자 | 높이 48px, 모서리 12px, 왼쪽 여백 16px. 선택 상자는 화살표 자리로 오른쪽 44px |
| 달력 팝업 | 모서리 20px, 날짜는 40px 원. 오늘은 노란 원, 고른 날은 회색 면에 검은 테두리 |
| 토스트 | 본문 위쪽 가운데, 흰 알약, 42px 아이콘 원 |
| 대화 상자 | 모서리 24px, 안쪽 여백 32px, 너비 560px |

## 5. 버튼 위계

- 검은 채움은 [AI 도우미에게 말하기]와 저장·확정 버튼에만 쓴다.
- [강의 추가], [직접 추가]처럼 손으로 넣는 버튼은 테두리 모양이다.
- 나란히 놓인 버튼은 큰 쪽 너비에 맞춘다.
- AI로 가는 버튼 이름은 모두 [AI 도우미에게 말하기 →]로 같다.
- 설정의 데이터 버튼은 비었을 때 [예시 데이터로 채우기], 데이터가 있을 때 [데이터 모두 비우기]다.
- 선택된 메뉴는 채운 아이콘, 나머지는 선 아이콘이다.

## 6. 문구 규칙

| 종류 | 규칙 |
|---|---|
| 제목 아래 한 줄 | 모든 메뉴에서 현재 상태(숫자)만 보여 준다. 예: "오늘 수업 1개 · 3일 안 마감 1건" |
| 카드 제목 아래 설명 | 모든 카드에서 쓰지 않는다 |
| 카드 아래 안내 문구 | 모든 카드에서 쓰지 않는다 |
| 지시 문구 | "먼저 ~하세요" 같은 말은 쓰지 않는다 |
| 남기는 것 | 남은 개수 같은 상태, 빈 상태 안내 |
| 도우미의 말 | 말은 검은색, "예:"는 다음 줄에 회색 |

한 종류를 빼기로 하면 모든 메뉴에서 뺀다. 메뉴마다 다르게 두지 않는다.

## 7. 빈 상태

- 모양은 색 점 세 개와 회색 문구 한 줄이다.
- 시간표가 비면 요일 줄 아래를 선 없는 빈 면으로 두고, 가운데에 안내와 버튼 두 개를 놓는다.
- 추가한 것이 없으면 '다가오는 마감', 'AI 도우미' 카드와 [전체 과제 보기]는 숨긴다.
- 계획이 없으면 순공 기록의 진행 막대와 과목별 누적도 숨긴다.

---

## 8. 움직임

- 완료 인터랙션: 일정에 무언가 들어가거나 끝났을 때만 누른 자리에서 색 점이 터진다. 대상은 AI 반영, 강의·과제 직접 추가, 계획서 만들기, 밀린 공부 다시 넣기, 과제 완료 체크, 순공 기록 저장이다. 수정, 삭제, 설정에는 쓰지 않는다.
- 'AI 연결됨' 아이콘은 그라데이션이 천천히 돌면서 반짝인다.
- `prefers-reduced-motion`이 켜져 있으면 움직임을 끈다.

---

## 9. 다시 맞추기와 되돌리기

- 어긋남은 네 가지로 본다. 마감 뒤에 잡힌 공부, 수업과 겹친 공부, 하지 못한 공부(이번 주 지난 날의 계획인데 그 과목 순공 기록이 없는 것), 공부 계획이 없는 일정.
- 어긋남이 있으면 첫 화면 제목 아래 상태 줄에 "어긋난 공부 계획 n건"을 보여 주고, 'AI 도우미' 카드에 [공부 계획 다시 맞추기]를 둔다.
- AI 도우미에 "수요일은 안 돼", "공부 못 했어", "마감이 밀렸어"라고 말해도 같은 제안이 나온다.
- 다시 맞추기는 항상 확인 카드를 거친다. 반영하면 오늘 이후의 공부 계획과 하지 못한 공부를 지우고 빈 시간에 다시 넣는다.
- 일정을 반영한 뒤 계획이 어긋나면 결과 말풍선에 그 내용과 [공부 계획 다시 맞추기]를 함께 보여 준다.
- 반영, 다시 맞추기, 계획서 만들기 직후에는 [되돌리기]를 보여 준다. 다른 조작을 하면 사라진다.

---

## 10. 알려진 한계

- 입력칸 안내 글의 대비가 4.5:1에 못 미친다(2.2절).
- 설정 화면에 검은 채움 버튼 [설정 저장]이 두 개 있다.
- Figma에는 달력 팝업과 순공 시간의 빈 상태 화면이 없다.
- 다시 맞추기는 하루에 넣는 공부 시간의 합계를 제한하지 않아, 하루에 여러 과목이 몰릴 수 있다.
- 되돌리기는 바로 직전의 한 번만 된다.
